StatDugout

Full-stack web app · Personal project · Sept 2025–present

An MLB stats site covering every season since 1969, with standings, rosters, player pages with career charts and splits, live daily scores, league leaders and side-by-side player comparisons.

  • Interactive JavaScript frontend with division filters, player modals and team-specific styling, plus Google or username sign-in to save favorite teams.
  • Containerized with Docker. Frontend and backend run as separate services on Render, with CORS configured between them.
